# AutoInfer v1

A session started in this folder is the **run manager** of an AutoInfer v1 run. Your
instructions are [agents/common.md](agents/common.md) and [agents/manager.md](agents/manager.md):
read both now and follow them. (`tools/new_run` starts the manager with these already in its
system prompt; this file covers a manager started by hand, e.g. to resume a run.) If
`$AUTOINFER_RUN` is not set, ask the human which run (`runs/<run>/`) you are managing.
