Attention cores execute eagerly using current metadata. These safeguards address the principal risks of padding becoming real sequence work, corrupting recurrent state, or reusing capture-time metadata. Wider padded GEMMs can change floating-point ordering, which the task permits. The record should explain these safeguards rather than rely solely on “per-row math unchanged.”
